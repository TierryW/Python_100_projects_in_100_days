# PYTHON 100 PROJECTS IN 100 DAYS

## Day 3: Treasure Island

### 📌 About The Project
In this project, I created a choice-based adventure game inspired by classic text RPGs and “Choose Your Own Adventure” stories.

The game starts on a mysterious island where the player must:
- choose different paths
- explore dangerous places
- find the correct treasure door

I first developed the game using terminal inputs and later improved it with a visual interface using Streamlit.

### 🧠 What I Learned
- Using `if`, `elif`, and `else`
- Creating branching story logic
- Handling user choices
- Using `.lower()` for input normalization
- Organizing game flow
- Using ASCII Art in Python
- Error handling for invalid options
- Using `st.session_state` to store game progress
- Creating interactive interfaces
- Using `st.columns()` for layout
- Creating restart systems
- Building scene-based navigation
- Updating pages dynamically with `st.rerun()`

### 🛠 Technologies Used
