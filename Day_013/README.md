## Day 13: Debugging — Squashing Bugs in Python

### 📌 About The Project
Today, the focus was on one of the most important skills in programming: **debugging**. Instead of simply writing new code, I practiced identifying, reproducing, analyzing, and fixing errors in Python programs. The main goal was to understand that bugs are a natural part of programming and that knowing how to investigate them systematically is just as important as knowing how to write code.

### 🧠 What I Learned
During this project, I practiced several techniques for finding and fixing bugs:

- **Describe the problem** — Clearly understand what is going wrong before trying to fix it.
- **Reproduce the bug** — Run the program and identify the exact situation that causes the error.
- **Play computer and evaluate line by line** — Follow the code manually to understand what Python is doing at each step.
- **Fix errors and watch for red underlines** — Use the editor's warnings and error indicators to identify potential problems.
- **Squash bugs with `print()` statements** — Print variables and intermediate results to discover unexpected values.
- **Use a debugger** — Use breakpoints and step-by-step execution to inspect the program while it is running.
- **Take a break** — Sometimes stepping away from the problem helps you return with a fresh perspective.
- **Ask a friend** — Explaining the problem to someone else can reveal mistakes that were difficult to notice alone.
- **Run often** — Testing the code frequently makes it easier to identify where a bug was introduced.
- **Ask Stack Overflow** — Search for solutions and learn from problems that other developers have already encountered.

### 🎯 Key Takeaway
Debugging is not about guessing what is wrong and changing random lines of code. It is a **systematic process of investigation**. The biggest lesson from today was that understanding how the code behaves is often more important than immediately trying to fix it. Tools such as `print()`, breakpoints, and debuggers make this process much easier and help develop better problem-solving skills.
