# PYTHON 100 PROJECTS IN 100 DAYS

## Day 14: Higher or Lower

### 📌 About The Project

In this project, I developed a **Higher or Lower** game in Python. The objective is to compare two randomly selected accounts and guess which one has more followers. After each correct answer, the score increases and the second account becomes the first account for the next round, while a new account is randomly selected. The game ends when the player chooses the account with fewer followers. I first developed the project as a terminal application and later created an interactive version using Streamlit.

### 🧠 What I Learned
- Managing application state with `st.session_state`
- Using `st.button()` to receive user input
- Generating random accounts with `random.choice()`
- Comparing follower counts between different accounts
- Keeping the score throughout multiple rounds
- Preventing the same account from being selected for both A and B
- Separating game data and ASCII art into different Python modules
- Updating the application interface with `st.rerun()`
- Creating responsive layouts with `st.columns()`
