# PYTHON 100 PROJECTS IN 100 DAYS

## Day 12: Number Guessing Game

### 📌 About The Project

In this project, I developed a Number Guessing Game in Python where the player needs to guess a randomly generated number between 1 and 100. The player can choose between two difficulty levels: Easy, with 10 attempts, or Hard, with only 5 attempts. After each guess, the game informs whether the chosen number is too high or too low until the player guesses the correct number or runs out of attempts. I first developed the project as a terminal application and later created an interactive version using Streamlit.

### 🧠 What I Learned
- Generating random numbers using `randint()`
- Creating difficulty levels with different numbers of attempts
- Receiving and validating user input
- Managing application state with `st.session_state`
- Using `st.number_input()` to receive numerical guesses
- Using `st.radio()` to select the game difficulty
- Updating the Streamlit interface with `st.rerun()`
- Controlling the game state with variables such as `game_started` and `game_over`
- Displaying feedback using `st.success()`, `st.warning()`, `st.info()`, and `st.error()`
