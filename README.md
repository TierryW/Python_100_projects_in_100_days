# PYTHON 100 PROJECTS IN 100 DAYS

## Day 1: Band Name Generator
### 📌 About the Project
A simple web application that generates a band name using the user's city and pet name.

### 🧠 What I Learned
- Variables in Python
- User input with `input()`
- String concatenation
- Basic Streamlit interface
- Deploying projects online using Streamlit Cloud
- Git and GitHub workflow

### 🛠 Technologies and Tools
- Python
- Streamlit
- VS Code
- Git
- GitHub

### 📚 Libraries Used

```python
import streamlit as st
```

### ▶️ How to Run the Project

1. Install Streamlit:

```bash
pip install streamlit
```

2. Run the project in the terminal:

```bash
streamlit run Day_1/webapp.py
```

3. Open the local link generated by Streamlit in your browser.

Example:

```text
http://localhost:8501
```
