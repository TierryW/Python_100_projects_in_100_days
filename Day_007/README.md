# PYTHON 100 PROJECTS IN 100 DAYS

## Day 7: Hangman Game

### 📌 About The Project
In this project, I developed the classic Hangman Game in Python. The player must guess a hidden word one letter at a time before running out of lives. For each incorrect guess, a life is lost and the hangman drawing progresses until the game ends.

I first developed the game using terminal inputs and later improved it with a visual interface using Streamlit.

### 🧠 What I Learned
- Working with lists `[]` and strings
- Using loops and conditional statements
- Managing game states
- Input validation
- Modularizing code with external files
- Managing persistent data with `st.session_state`

### 🛠 Technologies Used
- Python

- VS Code

- GitHub
- ASCII Art

### ▶️ How to Run the Project


