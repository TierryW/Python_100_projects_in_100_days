## Day 8: Ceasar Cipher

### 📌 About The Project
In this project, I developed a Ceasar Cipher application in Python. The Ceasar Cipher is one of the oldest and simplest encryption techniques. It works by shifting each letter of a message by a fixed number of positions in the alphabet. For example, with a shift of **3**, the letter **A** becomes **D**, **B** becomes **E**, and so on.

The application allows the user to encrypt and decrypt messages by choosing the desired shift value. I first developed the project using terminal inputs and later improved it with a visual interface using Streamlit.

### 🧠 What I Learned

- Using loops and conditional statements
- Applying the modulo operator `%` for cyclic shifts
