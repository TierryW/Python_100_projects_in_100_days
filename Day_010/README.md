# PYTHON 100 PROJECTS IN 100 DAYS

## Day 10: Calculator

### 📌 About The Project

In this project, I developed a Calculator in Python capable of performing the four basic arithmetic operations: addition, subtraction, multiplication, and division. The calculator allows users to perform multiple calculations continuously, validates numeric inputs, and handles invalid operations.
I first developed the project using terminal inputs and later improved it with a visual interface using Streamlit combined with HTML, CSS, and JavaScript.

### 🧠 What I Learned
- Creating and using functions
- Storing functions inside dictionaries
- Using loops to keep the calculator running
- Handling exceptions with `try` and `except`
- Embedding HTML, CSS, and JavaScript inside Streamlit
- Manipulating HTML elements with JavaScript
- Creating responsive layouts using CSS Grid
