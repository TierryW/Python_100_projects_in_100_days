# PYTHON 100 PROJECTS IN 100 DAYS

## Day 2: Tip Calculator

### 📌 About the Project
A simple web application that calculates the amount each person should pay when splitting a bill, including the selected tip percentage.

The user enters:
- The total bill amount
- The tip percentage
- The number of people splitting the bill

The application then calculates and displays how much each person should pay.

### 🧠 What I Learned
- Conditional statements using `if`
- Mathematical operations in Python
- Formatting decimal values with `round()`
- Improving user input validation and user experience
- Using `st.number_input()` for numeric inputs
- Using `min_value`, `step`, and `format`
- Using `st.selectbox()` to restrict user options

### 🛠 Technologies and Tools

### ▶️ How to Run the Project

1. Install Streamlit:

```bash
pip install streamlit
```

2. Run the project in the terminal:

```bash
streamlit run Day_2/webapp.py
```

3. Open the local link generated by Streamlit in your browser.
