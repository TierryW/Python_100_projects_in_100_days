# PYTHON 100 PROJECTS IN 100 DAYS

## Day 15: Coffee Machine

### 📌 About The Project

In this project, I developed a **Coffee Machine** in Python. The application simulates a coffee machine capable of preparing espresso, latte, and cappuccino. Each drink has its own ingredients and cost, while the machine keeps track of its available resources and total profit. I first developed the project as a terminal application and later created an interactive version using Streamlit, focusing on managing application state, creating a sidebar for the machine report, and dynamically accessing information stored in nested dictionaries.

### 🧠 What I Learned
- Creating a sidebar with `st.sidebar`
- Organizing information and controls inside the Streamlit sidebar
- Accessing values from nested dictionaries
- Dynamically accessing ingredients and prices from the `MENU` dictionary
- Iterating through dictionary keys and values with `.items()`
- Using `st.session_state` to preserve resources and profit between interactions
- Checking available resources before preparing a drink
- Calculating and displaying the customer's change
- Updating dictionary values when resources are consumed
- Using `st.metric()` to display the machine's current resources and profit
- Using `st.selectbox()` to dynamically select a drink
- Using `st.number_input()` to receive the number of coins
- Using `st.rerun()` to update the interface after a transaction
