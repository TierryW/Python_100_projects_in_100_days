# PYTHON 100 PROJECTS IN 100 DAYS

## Day 11: Blackjack

### 📌 About The Project

In this project, I developed a Blackjack game in Python that follows the classic casino rules. The game deals random cards to both the player and the dealer, automatically calculates scores, identifies Blackjack, applies the special Ace rule (1 or 11), and determines the winner based on the final hands. I first developed the project as a terminal application and later created a visual version using Streamlit.

### 🧠 What I Learned
- Managing application state with `st.session_state`
- Representing playing cards using dictionaries
- Creating and manipulating nested data structures
- Building a card deck with suits and ranks
- Implementing Blackjack game rules
- Dynamically adjusting the Ace value (1 or 11)
- Separating game logic into different Python modules
- Using list comprehensions to process data
- Combining multiple ASCII cards into a single drawing using `zip()`
- Joining strings with `" ".join()` to display cards side by side
- Creating responsive layouts with `st.columns()`
- Updating the interface with `st.rerun()`
