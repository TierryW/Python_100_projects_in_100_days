# PYTHON 100 PROJECTS IN 100 DAYS

## Day 9: Secret Auction Program

### 📌 About The Project
In this project, I developed a Secret Auction Program in Python. A secret auction is a type of auction where each participant submits their bid privately without knowing the bids of the other participants. When the auction ends, the participant with the highest bid wins.

The program collects each bidder's name and bid, stores all bids, and determines the winner by comparing the submitted values. I first developed the project using terminal inputs and later improved it with a visual interface using Streamlit.

### 🧠 What I Learned
- Working with dictionaries `{}` to store key-value pairs
- Iterating through dictionaries
- Creating and calling functions
- Finding the highest value in a collection
- Using loops and conditional statements
- Building forms with `st.form()`
