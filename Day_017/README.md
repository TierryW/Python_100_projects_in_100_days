# PYTHON 100 PROJECTS IN 100 DAYS

## Day 17: True or False Quiz

### 📌 About The Project

In this project, I developed a **True or False Quiz** in Python. The application presents a series of questions and allows the user to answer whether each statement is true or false. The project was initially developed as a terminal application using object-oriented programming and later created an interactive version using Streamlit.

### 🧠 What I Learned
- Creating classes to represent questions and manage the quiz
- Using object-oriented programming to organize the application logic
- Creating a question bank from a list of dictionaries
- Accessing values from dictionaries dynamically
- Creating methods to retrieve the current question
- Using `st.session_state` to preserve the quiz state between interactions
- Managing the current question number and score
- Checking the user's answer against the correct answer
- Using `st.columns()` to organize the True and False buttons
- Using `st.progress()` to display the user's progress through the quiz
- Using `st.metric()` to display the final score
- Using `st.rerun()` to refresh the interface after answering a question
- Creating a restart button to reset the quiz
