# PYTHON 100 PROJECTS IN 100 DAYS

## Day 4: Rock Paper Scissors (RPS)

### 📌 About The Project
In this project, I developed the classic Rock Paper Scissors game.

The player can choose between:
- Rock ✊
- Paper 🤚
- Scissors ✌️

After the player makes a choice, the computer randomly selects another option and the game displays:
- both choices
- ASCII Art visuals
- the final result (win, lose, or draw)

I first developed the game using terminal inputs and later improved it with a visual interface using Streamlit.

### 🧠 What I Learned
- Using lists in Python
- Using `random.choice()`
- Working with conditional logic
- Comparing multiple conditions
