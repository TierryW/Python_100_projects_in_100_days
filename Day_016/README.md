## Day 16: Coffee Machine - OOP

### 📌 About The Project

In this project, I developed a **Coffee Machine** in Python. The application simulates a coffee machine capable of preparing espresso, latte, and cappuccino. Each drink has its own ingredients and cost, while the machine checks the available resources and processes the customer's payment before preparing the selected drink.

The project was developed using **Object-Oriented Programming (OOP)** and separated into different modules, with each class responsible for a specific part of the coffee machine. The `Menu`, `CoffeeMaker`, and `MoneyMachine` classes work together to manage drinks, resources, payments, and reports.

### 🧠 What I Learned
- Creating and using **classes and objects**
- Importing classes from different Python modules
- Organizing a project into multiple files
- Using methods from different objects
- Understanding **Object-Oriented Programming**
- Passing objects as arguments to methods
- Separating responsibilities between different classes
